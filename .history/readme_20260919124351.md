# Modern Responsive Landing Page

A clean, modern, and fully responsive **Landing Page** built using **HTML5**, **Tailwind CSS**, and **Vanilla JavaScript**. Designed with a focus on UI/UX, fast performance, and seamless navigation across all screen sizes.

## ✨ Key Features

- 📱 **Fully Responsive:** Designed mobile-first, ensuring a flawless layout on Mobile, Tablet, and Desktop.
- 🧭 **Dynamic Navigation Bar:**
  - **Desktop:** CSS-driven dropdown menus on hover.
  - **Mobile:** Smooth accordion slide-down/up animation powered by Vanilla JS.
- 🎨 **Modern UI Design:** Clean layout, elegant typography, and consistent spacing using Tailwind CSS.
- ⚡ **Lightweight & Fast:** High performance with zero heavy JavaScript frameworks.
- ♿ **Accessibility & Semantics:** Built with semantic HTML elements and accessible ARIA attributes.

---

## 🛠️ Tech Stack

- **Markup:** HTML5 (Semantic)
- **Styling:** Tailwind CSS
- **Scripting:** Vanilla JavaScript (ES6+)
- **Icons:** FontAwesome
